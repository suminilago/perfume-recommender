# Recommendation Model Evaluation

## 1. 평가 목적

Content-based Filtering과 Item-based KNN의 추천 성능을 동일한 조건에서 비교.

사용자의 선호 향수가 Top-10 추천 결과에 포함되는지 평가.

## 2. 평가 데이터

### 데이터 구성

- Atrafshan 평점 데이터: 5,565건
- Fragrantica 콘텐츠 데이터: 24,063건
- 향수 ID 매핑 데이터: 1,369건
- 연결된 평점 데이터: 3,530건

위 수치는 현재 노트북 실행 결과 기준.

### Train/Test 분리

사용자별 Leave-One-Out 방식으로 테스트 평점 분리.

현재 실행 결과:

| 구분 | 평점 수 |
|---|---:|
| KNN 학습 | 5,204 |
| 콘텐츠 기반 사용자 프로필 구성 | 3,169 |
| 테스트 | 361 |

학습과 테스트의 사용자–향수 쌍 중복 여부 검사 결과: 0건.

단, 이 검사는 데이터 누수가 전혀 없음을 완전히 보장하는 것은 아님.

## 3. 추천 후보 선정

두 모델을 공정하게 비교하기 위해 공통 추천 후보를 구성.

- 공통 후보 향수: 666개
- 공통 추천 가능 사용자: 343명
- 관련 테스트 항목 보유 사용자: 286명

## 4. 평가 사용자 선정

현재 최종 평가 실행 결과:

- 최종 평가 사용자 후보: 326명
- 실제 지표 계산 사용자: 258명

## 5. 평가 기준

### Top-K 설정

K = 10

각 사용자에게 최대 10개의 향수를 추천하고 테스트 정답과 비교.

### 관련 아이템 기준

`RELEVANCE_THRESHOLD = 7.0`

테스트 평점이 7점 이상인 향수를 관련 아이템으로 정의.

## 6. 평가 지표

### Hit Rate@10

추천 목록에 관련 테스트 향수가 하나 이상 포함된 사용자 비율.

### Precision@10

추천한 10개 향수 중 관련 아이템이 차지하는 비율.

### Recall@10

사용자의 관련 테스트 아이템 중 추천 목록에 포함된 비율.

## 7. 모델 성능 결과

| 모델 | 사용자 | Hit Rate@10 | Precision@10 | Recall@10 |
|---|---:|---:|---:|---:|
| Content-based | 258 | 0.0620 | 0.0062 | 0.0620 |
| Item-based KNN | 258 | 0.0581 | 0.0058 | 0.0581 |

### 결과 해석

Content-based 모델의 Hit Rate@10이 Item-based KNN보다 0.0039 높음.

현재 평가 조건에서는 콘텐츠 기반 추천이 소폭 우세한 결과.

다만 이 차이만으로 콘텐츠 기반 추천이 일반적으로 더 우수하다고 결론 내릴 수 없음.

## 8. 평가의 한계

- 사용자 평점 데이터의 희소성
- 향수 데이터셋 간 매핑 범위 제한
- 공통 후보 향수로 평가 범위 제한
- 실제 평가에서 제외된 사용자 존재
- 단일 데이터 분할 결과만으로 일반화하기 어려움
